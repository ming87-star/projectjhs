계정·데이터 삭제 안내

벅스마스터 · Project JHS

삭제할 범위를 직접 선택하세요계정 전체 삭제와 게임 기록만 삭제는 서로 다릅니다. 이 안내를 읽거나 링크를 여는 것만으로 데이터가 삭제되지는 않습니다.계정 전체 삭제 · 계정 유지·게임 기록만 삭제 · 이 기기의 기록 삭제

1. 계정 및 클라우드 기록 전체 삭제

  1. 벅스마스터 웹 계정 삭제 페이지를 엽니다. 앱을 설치하지 않아도 이용할 수 있습니다.
  2. 게임에 연결했던 Google 계정으로 본인 확인을 합니다.
  3. ‘계정 및 클라우드 기록 영구 삭제’를 선택하고 확인 절차를 진행합니다. 성공 안내를 확인하세요.

앱에서는 타이틀 화면의 ‘저장 데이터 백업 · 옮기기 → 개인정보 및 데이터 관리 → 계정 및 클라우드 기록 삭제’를 이용할 수도 있습니다.

삭제: 벅스마스터의 Firebase 인증 계정(사용자 식별자와 연결된 이메일·표시 이름·프로필 사진 URL 등) 및 해당 계정의 클라우드 게임 기록(보유 곤충, 성장·관찰·전투 진행, 아이템·설정·보급 기록 등).

유지: Google 계정 자체와 Gmail, 다른 게임의 계정, 각 기기에 남아 있는 로컬 기록 및 직접 내려받은 백업 파일. Google 계정 전체를 삭제하는 기능이 아닙니다.

2. 계정은 유지하고 클라우드 게임 기록만 삭제

  1. 벅스마스터 타이틀 화면에서 ‘저장 데이터 백업 · 옮기기’를 엽니다.
  2. 기록을 저장했던 Google 계정을 연결한 뒤 ‘개인정보 및 데이터 관리’를 펼칩니다.
  3. ‘클라우드 기록 삭제’를 선택하고 삭제를 확인합니다. ‘계정 및 클라우드 기록 삭제’와 혼동하지 마세요.

삭제: 해당 계정의 클라우드 게임 저장 기록 전체. 개별 곤충이나 특정 경기 기록만 골라 지우는 기능은 제공하지 않습니다.

유지: 벅스마스터 Firebase 인증 계정과 계정 정보, 기기 내 게임 기록 및 내려받은 백업 파일. 계정은 이후에도 이용할 수 있습니다.

앱을 이용할 수 없거나 삭제가 되지 않으면 ming87@gmail.com으로 클라우드 기록만 삭제 요청을 보내 주세요. 제목이나 본문에 ‘벅스마스터 — 계정은 유지하고 클라우드 기록만 삭제’를 명시하고, 게임에 연결한 Google 이메일 주소를 알려 주세요.

삭제 후 ‘지금 저장’을 다시 누르면 기기에 남은 진행 내용이 클라우드에 새로 저장됩니다. 기록을 모두 지우려면 아래의 로컬 기록도 별도로 삭제해 주세요.

3. 이 기기에만 남은 기록 삭제

‘저장 데이터 백업 · 옮기기 → 개인정보 및 데이터 관리 → 이 기기의 기록 삭제’를 선택하면 해당 기기의 게임 진행 기록과 게임이 만든 자동 보관 사본이 삭제됩니다. 클라우드 기록과 다른 기기의 기록에는 영향을 주지 않습니다.

직접 내려받거나 다른 곳에 복사한 백업 파일은 저장한 위치에서 직접 삭제해야 합니다. 게임 기록 삭제는 연령대·광고 동의 등 별도 설정을 모두 지우는 기능이 아닙니다. 앱의 전체 로컬 데이터를 지우려면 Android 설정의 앱 저장공간 데이터 삭제를, 웹에서는 해당 사이트 데이터 삭제를 이용하세요.

4. 처리 시점과 남을 수 있는 정보

직접 삭제 기능은 본인 확인과 삭제 확인 후 서버에 삭제를 요청합니다. 정상 완료 안내가 표시되면 게임이 사용하는 클라우드 문서 또는 계정이 삭제된 상태입니다. 네트워크 오류 등으로 실패하면 다시 시도하거나 아래 연락처로 문의해 주세요. 삭제 전 보관을 원한다면 먼저 백업하세요.

계정 또는 게임 기록은 삭제 요청 전까지 보관되며, 삭제가 완료된 클라우드 게임 기록을 게임이 별도의 보관용 사본으로 만들지는 않습니다. 다만 서비스 제공업체의 보안 로그·백업 삭제 시점은 게임 화면의 완료 시점과 다를 수 있습니다.

Firebase 공식 안내상 인증 IP 로그는 수 주간 보관되고, 그 밖의 인증 정보는 계정 삭제 요청 후 운영·백업 시스템에서 제거되기까지 최대 180일이 걸릴 수 있습니다. 이 180일은 모든 게임 데이터의 보관 기간을 뜻하지 않습니다. Firebase 개인정보·보관 안내

계정을 유지하는 ‘클라우드 기록만 삭제’에서는 인증 계정 정보가 계속 남습니다. 광고 기능을 사용한 버전에서 Google이 처리한 광고 정보도 게임 계정 삭제만으로 모두 삭제되지는 않습니다. 해당 정보에는 Google 개인정보처리방침과 별도 보관·삭제 절차가 적용됩니다.

5. 직접 삭제하기 어렵다면

ming87@gmail.com으로 삭제 요청을 보내 주세요. 게임 이름 ‘벅스마스터’, 연결했던 Google 이메일, 원하는 삭제 범위(계정 전체 / 클라우드 기록만)를 적어 주세요. 비밀번호, 인증번호, 신분증은 보내지 마세요.

이메일 요청은 자동 삭제가 아닙니다. 본인 또는 정당한 대리인인지 확인한 후 처리 결과를 안내합니다. 연령 제한으로 기존 계정에 접근하지 못하는 경우에는 보호자와 함께 문의할 수 있습니다. 기기에만 있는 기록은 개발자가 원격으로 삭제할 수 없습니다.

삭제 요청을 위해 보낸 이메일은 게임 내 삭제 기능으로 함께 지워지지 않습니다. 문의 메일 자체의 삭제도 원하면 함께 요청해 주세요.

이 페이지는 로그인·광고·추적 스크립트가 없는 안내입니다. 메일 링크는 이용자의 메일 앱을 열며, 직접 전송하기 전에는 삭제 요청이 접수되지 않습니다.
