개인정보처리방침

시행일: 2026년 9월 11일 · 광고 포함 Android 베타

버전별 적용 안내아래 방침은 2026년 9월 11일부터 광고 SDK 및 연령별 계정 제한을 포함하는 대한민국 Android 베타 앱에 적용됩니다. 기기에 직접 설치한 테스트 버전도 포함합니다.광고 SDK가 없는 기존 공개 웹 게임과 기존 앱에는 2026년 9월 3일 개인정보처리방침이 적용됩니다. 이 안내나 광고 인증 파일의 공개만으로 게임이 업데이트되거나 광고가 활성화되지는 않습니다.

1. 적용 범위

이 개인정보처리방침은 모바일·웹 게임 벅스마스터가 이용자의 정보를 처리하는 방법을 설명합니다. 게임은 계정 연결 없이 로컬 기록만으로도 이용할 수 있으며, 이 방침이 적용되는 대한민국 Android 베타 앱에서는 Google 계정 연결과 Firebase 클라우드 저장·불러오기는 연령대를 확인한 만 14세 이상만 직접 선택해 이용합니다. 만 14세 미만과 연령 미확인은 기기 내 플레이 및 파일 백업을 이용합니다. 보호자 동의를 받아 신규 계정을 연결하는 기능은 제공하지 않습니다.

2. 처리하는 정보

  • 계정 정보: Google 로그인 시 Firebase Authentication을 통해 사용자 식별자(UID), 이메일 주소, 표시 이름 및 프로필 사진 URL을 처리할 수 있습니다.
  • 게임 기록: 이용자가 ‘지금 저장’을 선택하면 보유 곤충, 성장·관찰·전투 진행, 아이템 및 설정 등 게임 진행 데이터를 Firebase Firestore에 저장합니다.
  • 기기 내 기록: 계정을 연결하지 않아도 게임 진행 데이터가 해당 기기의 브라우저 또는 앱 저장공간에 저장됩니다. 이 정보는 이용자가 클라우드 저장을 선택하기 전에는 개발자 서버로 전송되지 않습니다.

연락처, 기기의 사진·마이크, 건강정보 또는 결제정보를 수집하지 않습니다. Google 계정 연결 시에는 인증·보안을 위해 Firebase가 IP 주소와 사용자 에이전트(브라우저·기기 환경 정보)도 처리할 수 있습니다. 정밀 위치 권한은 요청하지 않습니다. 광고 기능을 이용하면 아래와 같이 IP 주소 등을 통한 대략적인 위치와 광고 관련 정보가 처리될 수 있습니다. 별도의 게임 분석 SDK는 사용하지 않지만 광고 SDK는 광고 측정·진단 정보를 처리합니다.

3. 이용 목적

계정 정보는 본인 확인과 여러 기기에서 동일한 클라우드 기록을 찾는 데 사용합니다. 게임 기록은 이용자가 요청한 저장·불러오기 기능을 제공하고 진행 상태를 복원하는 데 사용합니다. Firebase 계정 정보와 게임 기록을 판매하거나 광고 타겟팅에 전달하지 않습니다. 광고 기능은 별도 Google 광고 SDK를 사용하며 이 베타 버전에서는 비개인화 광고를 요청합니다.

4. 처리 위탁 및 제공

로그인과 클라우드 저장을 제공하기 위해 Google LLC의 Google 로그인, Firebase Authentication 및 Firebase Firestore 서비스를 사용합니다. 해당 서비스는 기능 제공에 필요한 범위에서 정보를 처리합니다. 선택형 보상 광고에는 Google LLC의 AdMob 및 User Messaging Platform(UMP)을 사용합니다. 벅스마스터는 개인정보를 판매하지 않습니다.

5. 보관과 삭제

로컬 기록은 이용자가 앱 데이터나 브라우저 데이터를 지우거나 게임 안의 ‘이 기기의 기록 삭제’를 실행할 때까지 기기에 남습니다. 클라우드 기록과 연결 계정은 이용자가 삭제할 때까지 보관합니다.

게임의 ‘저장 데이터 백업·옮기기 → 개인정보 및 데이터 관리’에서 클라우드 기록만 삭제하거나 연결 계정과 관련 클라우드 기록을 함께 삭제할 수 있습니다. 앱을 설치할 수 없는 경우 웹 계정 삭제 페이지에서 요청할 수 있습니다. 삭제 요청이 성공하면 게임에서 사용하는 계정과 클라우드 저장 문서를 삭제하며, 벅스마스터가 이 게임 기록을 별도의 자체 사본으로 보관하지 않습니다. 서비스 제공업체의 보안 로그와 백업에는 별도의 삭제 주기가 적용될 수 있습니다. Firebase 공식 안내에 따르면 인증 IP 로그는 수 주간 보관되며, 다른 인증 정보는 계정 삭제 요청 후 운영·백업 시스템에서 제거되기까지 최대 180일이 걸릴 수 있습니다. 자세한 내용은 Firebase 개인정보 및 보안 안내를 참고해 주세요. 광고 서비스가 이미 처리한 정보의 보관·삭제에는 Google의 정책이 별도로 적용되며, 게임 계정 삭제가 Google의 모든 광고 기록 삭제를 의미하지는 않습니다.

6. 안전한 처리

클라우드 통신에는 HTTPS 암호화를 사용하며, Firebase 보안 규칙은 로그인한 이용자가 자신의 사용자 식별자에 연결된 게임 기록만 읽고 변경하거나 삭제하도록 제한합니다.

7. 이용자의 선택

Google 계정 연결은 선택 사항입니다. 언제든 계정 연결을 해제하고, 클라우드 기록을 삭제하며, 계정 자체를 삭제할 수 있습니다. 클라우드 계정을 삭제해도 기기 내 로컬 기록은 자동으로 삭제되지 않으므로 게임 안에서 별도로 삭제할 수 있습니다.

8. 선택형 광고와 연령대

계정 연결과 광고가 공유하는 이용 연령대는 만 14세 미만 / 만 14~17세 / 만 18세 이상 중에서 직접 선택합니다. 정확한 생년월일이나 신분증은 수집하지 않습니다. 선택값은 Android 앱의 기기 설정 또는 웹 브라우저의 별도 로컬 설정에 저장하며 게임의 Firebase 저장 데이터에 넣지 않습니다. Android 자동 백업 및 기기 간 이전에서도 이 설정을 제외합니다. 이는 본인 확인이나 인증된 연령이 아니며 게임 입장 제한을 대신하지 않습니다. 연령 확인 전에는 게임의 Firebase 웹 SDK를 자동으로 초기화하거나 클라우드 로그인 세션을 복원하지 않습니다. Android 앱에는 별도의 네이티브 Firebase 구성요소가 포함됩니다. 만 14세 미만으로 변경하면 진행 중인 연결을 해제하고 클라우드 저장·불러오기를 차단합니다. 이 기기의 진행 기록 및 기존 클라우드 기록은 자동 삭제하지 않습니다. 기존 계정의 삭제가 필요하면 보호자와 함께 웹 계정 삭제 페이지에서 삭제 절차를 이용할 수 있습니다.

선택형 추가 보급은 해당 기능이 활성화된 Android 앱에 한해 제공하며, 웹 미리보기에서는 실제 광고나 추가 보급을 제공하지 않습니다. 연령 미확인 또는 만 14세 미만에게는 광고를 요청하지 않습니다. 만 14세 미만 이용자는 광고 없이 하루 1회 촘촘한 그물 3개 또는 맞춤 영양 보급 1개 중 선택해 받을 수 있습니다. 두 선택은 같은 일일 추가 보급 횟수를 사용합니다. 만 14세 이상은 하루 최대 3회 선택형 보상 광고를 이용할 수 있고, 청소년 광고 요청에는 청소년 보호 설정을 적용합니다. Android 광고 ID 접근 권한을 제외하고 비개인화 광고를 요청하지만, 앱 세트 ID와 IP 주소 등의 처리까지 없어지는 것은 아닙니다. 기존 무료 보급과 로컬 게임 이용은 광고 시청 여부와 무관하게 유지됩니다.

테스트 광고도 Google 서버와 통신하므로 아래 데이터 처리 안내가 적용됩니다. 현재 검증용 베타는 Google 테스트 광고만 요청하며, 이 방침을 게시하는 것만으로 실제 수익 광고가 활성화되지는 않습니다.

광고 이용 시 Google 광고 SDK가 IP 주소(대략적인 위치 추정에 이용 가능), 광고 노출·동영상 시청·탭 등 상호작용, 앱·SDK 성능 및 진단 정보, 앱 세트 ID와 해당되는 기기·계정 식별자를 처리할 수 있습니다. 목적은 광고 제공·측정, 오류 진단 및 부정 이용 방지입니다. 앱은 Android 광고 ID 권한을 제외하지만, 이것이 모든 기기 식별자나 광고 관련 정보의 처리를 막는다는 뜻은 아닙니다.

광고 요청은 사용자의 선택 및 필요한 동의 절차를 거칩니다. 비개인화 광고도 데이터 처리가 전혀 없는 광고는 아닙니다. 광고 데이터는 전송 중 암호화되며 Google 서비스의 처리 지역과 보관 정책은 Google 개인정보처리방침을 따릅니다. 광고 개인정보 선택 화면이 필요한 경우 도구함의 ‘광고 개인정보 선택’에서 다시 열 수 있습니다. 동의하지 않거나 광고를 취소해도 기존 무료 보급을 이용할 수 있습니다.

연령대를 변경해도 그날의 추가 보급 사용 기록은 초기화하지 않습니다. 보급 횟수와 수령 기록은 게임 저장 데이터에 포함되며 선택형 클라우드 저장 시 함께 보관됩니다. 앱 데이터 삭제·저장 복원·다중 기기에 대한 계정 전체 횟수 제한은 현재 제공하지 않습니다.

9. 변경

광고, 결제, 분석 도구 또는 새로운 온라인 기능이 추가되어 정보 처리 방식이 달라지면 이 방침과 Google Play 데이터 보안 정보를 먼저 갱신하고 시행일을 표시합니다.
